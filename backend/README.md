# Smart Campus Emergency Response System

A smart emergency response system designed to improve safety and emergency management inside a campus.

## Project Overview

The Smart Campus Emergency Response System helps students and campus authorities during emergency situations.

The system provides features such as:

- Emergency/SOS support
- Incident reporting
- Real-time alerts
- Nearby shelter identification
- Nearby medical center identification
- Safe route and navigation support
- Location and map services
- Firebase database integration
- AI and external API integration

## Backend

The backend is developed using Python and provides services for emergency management, maps, database operations, shelters, and external integrations.
